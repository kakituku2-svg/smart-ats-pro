# AI Apps Suite

複数のAI支援アプリをまとめて管理するAndroid / Webアプリ開発リポジトリです。

旧リポジトリ名 `smart-ats-pro` は初期のSmart ATS開発時の名称で、現在の内容とは一致していません。

## 主なアプリ

### AI制作工房
- Androidソース: `ai-seisaku-kobo-android/`
- アプリ名: `AI制作工房`
- applicationId: `jp.kakituku.aiseisakukobo`
- Androidネイティブ音声認識対応
- Android内部バージョン: `1.2.0`

### Smart ATS
- 採用管理・AI支援アプリ
- 旧プロジェクト由来のソースを保持

### KEIRIN AI / Race Gate
- 競輪分析・予想プロンプト生成関連
- `keirin-android/`
- `keirin-android-standalone/`
- `keirin-race-gate/`

### 設定看破AI
- パチスロ分析関連Androidアプリ
- `settei-kanpa-ai-android/`

## リポジトリ名について

現在の内容に合わせ、推奨リポジトリ名は `ai-apps-suite` です。
GitHub上のリポジトリ名変更後も、各アプリのパッケージ名・ソース構成はそのまま維持できます。

## セキュリティ

実APIキー、署名鍵、個人情報、秘密情報は公開リポジトリへコミットしないでください。
