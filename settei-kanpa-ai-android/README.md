# SETTEI KANPA AI v4.1 Android

設定看破AI STORE INTELLIGENCE v4.1 のAndroidスタンドアロン版です。

- Web版と同じv4.1予測ロジックをAPK内に内蔵
- 朝予測 / 店舗深掘り / イベント癖 / LIVE再判定 / 収支 / 小役
- APKはGitHub Actionsの `SETTEI-KANPA-AI-v4.1.0-APK` artifactから取得
- `app.html.gz.b64` をアプリ起動時にネイティブ側で展開するため、WebViewの圧縮API対応状況に依存しません
